# Factory attendance demo
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Workers using a shared factory gate terminal; students demonstrating the capstone.

## Product Purpose
Record invented workers clocking in and out, and show persistent attendance records.

## Operating Context
Required laptop-hosted Cloudflare quick-tunnel demo, separate from the AWS deployment. Desktop and mobile browsers are equally supported.

## Capabilities and Constraints
Next.js and shadcn. Local PostgreSQL in Docker. Worker selection, clock-in, clock-out, and recent records. No login, biometrics, payroll, or real personal data. Database credentials are server-only. The user approved this scope and delegated visual details.

## Brand Commitments
Mekong Apparel is the fictional client supplied by the assignment.

## Evidence on Hand
The capstone document is in the parent folder. All seeded workers are explicitly invented demo data.
